# 전기 자동차 충전소

마을 사무소에서는 마을의 공해를 줄이기 위해 주민들에게 한 집당 한 대씩 전기자동차를 보급하고, 전기자동차 충전소를 만들려고 한다.

마을에는 N개의 집이 있으며 (2 <= N <= 20), 마을의 전체 좌표는 X축과 Y축 방향 모두 -15에서 15까지이다. 각 집의 위치는 (x, y)로 주어진다. (-15 <= x, y <= 15)

집과 충전소 사이의 거리는 맨해튼 거리로 계산한다. 집의 위치가 (XH, YH), 충전소의 위치가 (XC, YC)라면 거리는 `|XH - XC| + |YH - YC|`이다.

**모든 집에 전기자동차가 보급될 수 있도록 충전소의 위치를 선정할 때, 충전소와 N개의 집 사이 거리의 합이 최소가 되는 값을 구하는 프로그램을 작성하라.**

**[조건]**

1. 충전소는 **가능한 최소 개수만 지어야 하며,** 최대 2개까지 지을 수 있다. 충전소 1개만으로 모든 집의 허용 거리 조건을 만족할 수 있다면 반드시 1개만 지어야 한다.
2. 충전소를 2개 지을 경우 각 집의 거리는 두 충전소 중 더 가까운 충전소와의 거리로 계산한다.
3. 충전소를 2개 지어도 허용 거리 내에 충전소가 없는 집이 존재하면 `-1`을 출력한다.
4. 집이 있는 위치에는 충전소를 지을 수 없다.

**[예시 설명]**

- A집의 위치가 (-2, 0), 허용 가능한 최대 거리가 1이고 B집의 위치가 (1, 3), 허용 가능한 최대 거리가 2라면 반드시 2개의 충전소가 필요하며 거리 합의 최솟값은 `2`이다.
- A집이 (-1, -1), 허용 거리가 1이고 B집이 (1, 0), 허용 거리가 2인 경우에는 충전소 1개만으로 두 집을 모두 만족시킬 수 있으며 정답은 `3`이다.
- 충전소 2개를 건설하더라도 모든 집의 허용 거리 조건을 만족시키지 못하면 정답은 `-1`이다.

**[제약사항]**

1. 집의 개수 N은 2 이상 20 이하의 정수이다. (2 <= N <= 20)
2. 집의 좌표 (x, y)는 -15 이상 15 이하의 정수이다. (-15 <= x, y <= 15)
3. 각 집에서 충전소까지 허용 가능한 거리 d는 1 이상 30 이하의 정수이다. (1 <= d <= 30)

**[입력]**

첫 줄에 테스트 케이스의 개수 T가 주어진다. 이후 각 테스트 케이스가 이어진다.

각 테스트 케이스의 첫째 줄에는 집의 개수 N이 주어진다.

다음 N개의 줄에는 각 집의 위치 x, y와 해당 집에서 충전소까지 허용 가능한 거리 d가 공백으로 구분되어 주어진다.

**[출력]**

각 테스트 케이스마다 `#t 정답` 형식으로 출력한다. `t`는 1부터 시작하는 테스트 케이스 번호이다.

- sample_output

```text
#1 2
#2 3
#3 36
#4 -1
#5 21
```
