# 문제를 풀기 위한 기초 구현

아래 파일은 각각 독립적으로 실행할 수 있는 작은 예제입니다. `input.txt`를 읽거나 기존 풀이 파일을 변경하지 않습니다.

1. `01_manhattan.py` — 맨해튼 거리와 허용 거리 판정
2. `02_grid_search.py` — 격자의 모든 후보를 확인하고 두 자리를 조합으로 선택
3. `03_bitmask.py` — 집별 커버 여부를 비트마스크로 기록하고 합치기
4. `04_one_station_first.py` — 충전소 1개가 가능하면 반드시 1개를 선택
5. `05_two_stations.py` — 2개로 커버 가능한지 확인하고 가까운 쪽 거리의 합 계산

프로젝트 폴더에서 `python concepts/01_manhattan.py`처럼 실행하면 예제 결과를 볼 수 있습니다. 번호 순서대로 읽은 뒤 `solve.py`에서 개념이 합쳐진 모습을 확인하세요.
